Odoo est un ERP open source complet couvrant la gestion des ventes, stocks, facturation, e-commerce et point de vente. Contrairement aux solutions propriétaires coûtant des milliers de dollars en licences, Odoo Community est 100% gratuit. Cela nous permet de proposer une solution professionnelle complète pour un abonnement mensuel accessible aux commerces haïtiens.
Les PME haïtiennes ont besoin de se digitaliser pour croître mais les solutions traditionnelles exigent des investissements de plusieurs milliers de dollars. Proaktif Consulting élimine cette barrière en proposant une infrastructure numérique complète (caisse POS, gestion stocks, site e-commerce) pour le prix d'un abonnement mensuel — sans capital initial requis.
Commerce, Restaurant, E-commerce, Site vitrine : basés sur les modules natifs d'Odoo (point de vente, stock, boutique en ligne).
École : gestion scolaire avec bulletins au format haïtien (développé par mon associé).
Clinique / Hôpital : module que j'ai développé de zéro (voir le projet ci-dessous).
Barber Shop : pensé pour le fonctionnement local, avec file d'attente sur place et vente de boissons en plus des coupes.
Déploiement et administration de l'infrastructure VPS multi-tenant sur Hetzner. Configuration de Docker Compose orchestrant Odoo, PostgreSQL et Traefik avec SSL wildcard automatique. Développement de scripts Bash automatisant l'onboarding, la suspension et la sauvegarde des clients. Mise en place du workflow Git avec branches, Pull Requests et code review.
Architecture multi-tenant : une instance Odoo et une instance PostgreSQL servent plusieurs clients, chacun avec sa propre base de données isolée et son sous-domaine sécurisé en HTTPS. Serveur durci (pare-feu, protection contre les tentatives d'intrusion, accès SSH par clé uniquement) et sauvegardes automatiques chaque nuit.
